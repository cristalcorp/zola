This article is about hosting this [zola](https://www.getzola.org/) blog on GitHub, using GitHub pages and GitHub actions.

# Zola

## Step 1 : Installing Zola
Following the official [doc](https://www.getzola.org/documentation/getting-started/installation/), install Zola as follows
```bash
yay -S zola
```
Then initializing a new project
```bash 
zola init [project_name]
```

## Step 2 : Theme
I decided to go with [Terminus](https://www.getzola.org/themes/terminus/) a port of Hugo [Terminal](https://themes.gohugo.io/themes/hugo-theme-terminal/) theme I believe.  
As the documentation suggests, install it as a git sub module
```bash
git submodule add https://github.com/ebkalderon/terminus.git themes/terminus
```
Note that if you clone a repo which uses a theme installed a git submodule, you will have to initialize it before being able to use it.
```bash
git submodule update --init --recursive
```
