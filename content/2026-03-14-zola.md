# Zola

## Step 1 : Installing Zola
Following the official [doc](https://www.getzola.org/documentation/getting-started/installation/), install Zola as follows
```bash
yay -S zola
```
Then initializing a new project
```bash 
zola init [project_name]
```

## Step 2 : Theme
I decided to go with [Terminus](https://www.getzola.org/themes/terminus/) a port of Hugo [Terminal](https://themes.gohugo.io/themes/hugo-theme-terminal/) theme I believe.  
As the documentation suggests, install it as a git sub module
```bash
git submodule add https://github.com/ebkalderon/terminus.git themes/terminus
```
Note that if you clone a repo which uses a theme installed a git submodule, you will have to initialize it before being able to use it.
```bash
git submodule update --init --recursive
```
And to update the theme
```bash
git submodule update --remote themes/terminus
```

## Step 3 : Configuration
The configuration is pretty straight forward and very little is needed to get started. Everything happens in the config.toml file... For me. If you follow the official [doc](https://www.getzola.org/documentation/getting-started/configuration/) it appears that the configuration should be stored in the zola.toml file, zola using config.toml only as a fallback / backward compatibility option. In my case, using the zola.toml file did not work, maybe my configuration was missing something, I will dig into it later... maybe. Anyway this is the bare minimum
```toml
base_url = "https://theurlofyourdreams.com"
title = "self explanatory"
theme = "terminus"
compile_sass = true
build_search_index = false

[markdown]
[markdown.highlighting]
theme = "catppuccin-mocha"

[extra]
```

## Step 4 : Start
Fill up your content folder and start your local server with
```bash
zola serve
```
You should be good to go !
